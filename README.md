# T-FLEX_PM_test — Geometry Figures

Учебное WPF-приложение на C# для демонстрации ООП на примере геометрических фигур.

## Возможности

- создание круга, квадрата, прямоугольника и треугольника;
- динамическое создание полей ввода в зависимости от выбранной фигуры;
- проверка геометрических параметров;
- вычисление площади и периметра;
- отрисовка фигур на WPF Canvas с масштабированием под область просмотра.

## Архитектура

- `T-FLEX_PM_test` — библиотека классов `Infrastructure`: базовый абстрактный класс `AFigure`, реализации фигур, `FigureType` и `FigureFactory`.
- `View` — WPF-приложение: ввод параметров, вызов фабрики и отрисовка.

Библиотека фигур не зависит от WPF. Интерфейс зависит от библиотеки через `ProjectReference`.

## Требования

- .NET 10 SDK;
- Windows (WPF запускается на Windows);
- Visual Studio 2026 с компонентом разработки классических приложений .NET, либо .NET SDK.

## Запуск

Откройте `T-FLEX_PM_test.slnx` в Visual Studio и запустите проект `View`.

Либо из каталога решения выполните:

```powershell
dotnet run --project .\View\View.csproj
```

## Примеры параметров

| Фигура | Параметры | Пример |
|---|---|---|
| Круг | Радиус | `5` |
| Квадрат | Сторона | `4` |
| Прямоугольник | Ширина, высота | `6`, `3` |
| Треугольник | Стороны A, B, C | `3`, `4`, `5` |

Для треугольника проверяется неравенство треугольника. Все размеры должны быть конечными положительными числами.
